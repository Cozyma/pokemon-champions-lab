# 行動回数の収支理論と戦略フレーム（2026-04-24）

## 1. 基本原理

勝利条件は「相手の行動回数を0にする（全滅）」。
全ての行動は**行動回数の収支**で統一的に評価できる。

### 行動回数の増減

**自分の行動回数を増やす:**
- 耐久（2発耐える = 2回行動できる）
- 回復（行動回数を回復）
- あくび（眠りで相手の行動を封じ、裏の安全着地 = 裏の行動回数を保証）

**相手の行動回数を減らす:**
- 攻撃（HPを削る → 倒す = 行動回数0に）
- 先制して倒す（被弾なし = こちらの行動回数減少なし + 相手の行動回数-1 = 最高効率）
- ステロ/定数ダメ（交代ごとにHP削り → 倒すまでの残り必要行動数を減らす）
- タスキ/マルスケ潰し（行動保証を剥がす = 相手が想定した+1回をなくす）

**行動回数を変換する:**
- 積み技（自分の1行動を投資 → 以降の行動効率が上がる = 少ない行動で倒せる）
- U-turn（1行動で情報+安全交代 = 行動回数を失わず有利対面を作る）

### 最高効率の行動

**先制して倒す**ことが最高効率。被弾による自軍の行動回数減少をゼロにしつつ、相手の行動回数を減らしている。

ただし多くの場合、明らかに先制して倒せる有利対面では相手は交代する。これが**サイクル戦**の起点:
- 相手の交代 = 「倒しに行く技」の行動阻害
- 交代先が有利対面を取り返す = 次は自分が倒される側になる
- → 交代の連鎖で行動回数の収支を競う

## 2. 戦略フレーム: サイクル↔起点のスペクトラム

戦略は排他的なカテゴリではなく、**交代による行動回数の収支管理を基本原理とした連続スペクトラム**:

```
ディフェンシブサイクル
  │  受け回して相手の行動を枯らす（空振りさせる）
  │  ローリスク・ローリターン
  │
オフェンシブサイクル
  │  交代先への負荷で「どう行動しても倒される」状況を作る
  │  純粋対面はこの極端なケース（交代回数を最小化した変種）
  │  │
  │  └─ サイクル中の積み
  │      交代先に対して最も効率的な負荷が積み技である場合に選択
  │      (例: 有利対面で竜舞 → 交代先ごと破壊)
  │
純起点展開
     あくび/SR → 退場 → 積みエースで全抜き
     サイクルを放棄して投資→回収に全振り
     ハイリスク・ハイリターン
```

**積みは独立した戦略ではなく、「この対面で最も行動回数効率が良い選択肢が積みだった」という判断の結果**。
クエスパトラ型はその極端な形で、起点作りから展開まで全てを積みに集約している。

### モード切り替え: カバルドンの例

カバルドンの強さは「サイクル↔起点をモード切り替えできる」点にある:

```
サイクルモード: EQ/SR/あくびで行動回数を稼ぐ汎用駒
起点モード:    あくび連打 → 裏の無償着地 → 積みエース展開

モード切り替えの判断:
  「今サイクルを続けるより、ここで起点に移行した方が行動回数の総収支が良い」
```

T1あくび(WR46%)の強さは「起点モードにも入れるし、相手が交代すればサイクルとしても機能する」= **どちらのモードにも分岐できる行動**。

ただしあくびの成否はカバルドンが対面で何発耐えるかで大きく変わる:

```
3発以上耐える対面（最も強い）:
  T1 あくび → T2 SR → T3以降も行動可能
  → あくび+SRの2手が確実に成立
  → SRで相手のタスキ/マルスケを潰し、後続の積みエースが全抜き体制
  → 行動回数の投資→回収が最も確実

2発で倒される対面:
  T1 あくび → T2 SR → T2で被弾2で倒される（SR撒けるかは先制次第）
  or T1 あくび → T2 被弾2で倒される → 相手は眠り
  → 後続がフリーで1-2回積める
  → ただしSRなしだとタスキ/マルスケが残っており全抜きが不確実
  → カバルドンの犠牲(2行動)で後続のフリー1-2回を買う、リスキーなプラン

1発で倒される対面:
  → あくびは打てるが、SRは撒けない
  → 起点としての投資効率が低すぎる

あくびが機能しないケース:
  - U-turn/Volt Switch持ち → あくび後にピボットで逃げて眠りが発生しない
  - 挑発持ち → あくび自体が封じられる
  - ラムのみ/カゴのみ → 眠りを即回復、こちらの行動1回がロス
```

**先発の対面相性が戦略全体の成否を左右する**。これが「選出+T1で大勢が決まる」の理論的説明:

```
team previewで相手の6体を見る
→ あくびが通る対面（3発耐え、ピボットなし）を作れるか判断
→ 作れるなら起点展開ルート（Hippowdon先発）
→ 作れないならサイクルルート（別の先発、あくびは中盤以降に温存）
```

### T1行動の順序: Yawn先 vs SR先

リプレイ検証（R1200+, Hippowdon先発60件）:

| 順序 | 件数 | WR | 退場率 |
|------|------|-----|--------|
| **Yawn → SR** | 14 | **36%** | 50% |
| **Yawn → Yawn** | 6 | **50%** | — |
| SR → Yawn | 11 | 9% | 71% |

統計上はYawn先が圧倒的。SR先は相手にフリーの攻撃を許し、選択圧なしに被弾→2発目を撃つ前に倒される展開になりやすい。Yawnなら「居座って眠るか、交代してSR/追加行動を許すか」の二択を強いる。

**ただしSR先が最効率になる条件は存在する:**
- 相手の攻撃を2発耐える（SR+Yawnの2手が保証される）
- 相手が交代せず居座る読み（あくびが空振りするリスクを避けたい）
- 相手にラムのみ持ちの可能性が高い（あくびの空振りリスクが大きい）
- 裏のエースがタスキ/マルスケ持ちの処理にSRが必須

→ ヒューリスティクスには「Yawnをデフォルト、SR先は上記条件を満たす場合のみ」として実装すべき。

- **Hippowdon T1 Yawn**: カバルドンが2発耐える耐久があるから成立する。2回行動が保証されるため、あくび+SRの2手を確実に打てる。

- **Glimmora Power Gem**: 先手で倒せるケース(対面有利)は殴る方が行動回数効率が高い。設置は対面不利時のみ。

## 5. ヒューリスティクスへの示唆

### 現在の積み判定の問題

現在: 「安全に積めるか」で判断。
本来: 「積むことが交代先への負荷として最も効率的か」で判断すべき。

```
目の前を倒せる → 倒す（直接行動回数-1、最高効率）
目の前を倒せないが積めば交代先ごと倒せる → 積む（投資）
目の前も交代先も厳しい → 交代（行動回数保全）
```

### 行動選択の評価基準

技の即時ダメージスコアだけでなく:
- **この行動で相手にどんな選択肢を強いるか**
- **相手のどの選択肢でも行動回数の収支がこちら有利か**（あくびの強さ）
- **交代先への波及的な負荷**（積みの評価）
- **行動回数を消費せず状況を改善できるか**（U-turnの評価）

## 6. 実例分析: joguri構築 (WR85%, 13件)

### 構築と基本プラン

```
Charizard / Clefable / Espathra / Garchomp / Hippowdon / Rotom-Wash
```

**起点オールイン**: Hippowdon先発(11/13) → あくび/SR → 退場 → Espathra着地 → かそく+瞑想連打 → 全抜き or バトンタッチ→Clefable引き継ぎ

Espathraの特性「かそく」で毎ターン素早さ+1。瞑想と合わせて積めば積むほど行動回数の投資効率が上がり、バトンタッチで投資が無駄にならない。

### 勝ちパターン (9勝)

ほぼ全勝試合が同じ流れ:
1. Hippowdon: Yawn or SR（2手保証の耐久が前提）
2. Hippowdon退場 → Espathra着地
3. Espathra: Protect+Calm Mind交互 → Lumina Crash or Baton Pass→Clefable

### 負けパターン (2敗)

- vs Mega Banette: Poltergeistでゴースト高火力に全員倒される
- vs Meowscarada+Rotom: あくびを回避されてEspathra起点を作れず

### 裏択

| 条件 | 先発 | 理由 |
|------|------|------|
| デフォルト | Hippowdon | 起点展開 |
| vs Garchomp(設置ミラー) | Garchomp | ミラー回避 |
| vs 起点にされそうな相手 | Espathra直出し | 先に積む |

### 限界

WR85%は高いが、Espathra起点展開は**戦略がバレれば対策される**:
- ゴースト高火力(Poltergeist等)でEspathraを即倒し
- あくびをU-turn/挑発で回避 → 起点を作らせない
- Espathraに先制で高火力を叩き込む

上位帯では対策構築が増えるため、**裏択（Espathra以外の勝ち筋）を用意して使い分ける**必要がある。joguri構築はCharizard/Rotom-Washが裏択候補だが、リプレイ上ではほぼEspathra展開のみで勝っており、裏プランの洗練が課題。

## 7. Smogonロール分類との照合

Smogon BSS Role Compendium (Reg M-A)の分類を行動回数理論で再解釈。
理論を変えるものではなく、具体的な技・特性の列挙として有用。

### 現在のヒューリスティクスに不足している評価

| 不足項目 | 行動回数への影響 | 該当技/特性 |
|---------|-----------------|------------|
| **Phazing(強制交代)** | ステロ+Dragon Tailで毎回定数ダメ=相手の行動回数を間接削り | Dragon Tail, Roar, Whirlwind |
| **Trapping(拘束)** | Shadow Tag以外の拘束で相手の交代=行動回数保全を封じる | Fire Spin, Whirlpool, Infestation |
| **Taunt/Encoreへの対応** | 積み/回復/設置を封じられる=行動回数の投資が不可能に | Taunt, Encore |
| **Weather連携** | 天候下でのアビリティ加速=実質的な行動回数増加 | Sand Rush, Chlorophyll, Swift Swim |
| **Baton Pass評価** | 積みの投資を他のポケモンに引き継ぎ=投資の回収率を上げる | Baton Pass(Espathra, Clefable) |
| **Stored Power/Power Trip** | 積み量に比例して火力増=投資の回収効率が指数的に上がる | Stored Power(Espathra), Power Trip |

### 外部データソースの調査結果

BSSシングルReg MAの大規模統計は自前リプレイ(1,255件)が最大。
VGCダブルス統計(showdowntier: 107k試合, pokemonchampionsmeta: 445チーム)は存在するがメタが異なり直接使えない。
→ 統計ベースではなく理論ベースでヒューリスティクスを構築する方針。

| パターン | 投資 | 回収 | 構築例 |

### 電磁波 vs あくびの理論的比較

```
あくび:
  2-3ターンの行動封じ(一時的) / 交代・ラムで回避可能
  → 後続に確実なフリー行動を提供するが、相手の対策で空振りリスク

電磁波:
  S永続半減 + 1/4で行動不能(恒久的) / 交代しても効果残存
  → 1行動の投資で以降の全ターンで行動回数の期待値をこちら有利にする
```

どちらが優位かは対面と構築による。あくびは起点展開、電磁波はサイクル戦との相性が良い。
