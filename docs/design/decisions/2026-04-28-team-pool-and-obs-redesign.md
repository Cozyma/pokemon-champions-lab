# 対戦相手プール拡大・観測空間再設計（2026-04-28）

## 背景

Self-Play(Phase 4)がpolicy forgettingで失敗（4/23）。原因分析から2つのボトルネックを特定:

1. **対戦相手の多様性不足** — 11チームではメタの幅をカバーできず、Self-Playの初期方策が弱い
2. **観測空間の情報不足** — 選出obsはタイプのみ(同タイプ異種族を区別不能)、バトルobsは相手の技・控え情報が欠落

4/24〜4/28に収集したゲーム内上位構築コレクション(28件、R2000〜R2500)の資産を活用し、両方を同時に解消する。

## 2. 選出環境の観測空間再設計（216dim → 360dim）

### 問題

旧obs(216dim)はタイプ情報(18dim one-hot × 12スロット)のみ。
同タイプの異種族（例: Corviknight鋼/飛 vs Skarmory鋼/飛）を区別できない。

### 新設計

スロットあたり30dim × 12スロット(自6体+相手6体) = **360dim**

| フィールド | 次元 | エンコード |
|-----------|------|-----------|
| タイプ(既存) | 18 | multi-hot |
| 基礎ステータス | 6 | hp/atk/def/spa/spd/spe / 200.0 |
| 役割指標 | 3 | physical_bias=(atk-spa)/200, special_bias=(spa-atk)/200, bulk=(hp+def+spd)/600 |
| 特性フラグ | 3 | contact_punish, type_immunity, setup_potential |

### 実装

| ファイル | 変更内容 |
|---------|---------|
| `src/pokechamp/selection_env.py` | `_encode_species_full()` 新設、`SELECTION_OBS_DIM=360`、obs_space low=-1.0 |

## 3. バトル環境の観測空間再設計（101dim → 186dim）

### 問題

旧obs(101dim)の主な欠落:
- 相手の技情報がゼロ → 対面の有利不利を判断できない
- ステータス変化(積み)が観測に含まれない → 積まれた相手に居座るか交代するか判断できない
- 設置技(SR/まきびし)の状態が見えない
- 相手の控え情報が「生存数」3dimだけ → 交代先の判断材料が不足

### 新設計（186dim）

| セクション | 旧 | 新 | 変更 |
|-----------|-----|-----|------|
| 自分のアクティブ | 26 | 26 | — |
| 自分の技 | 20 | 20 | — |
| 相手アクティブ | 28 | 28 | — |
| **相手判明技** | **0** | **16** | 4スロット×(bp,eff,stab,cat) |
| 自チームHP | 3 | 3 | — |
| ~~相手生存数~~ | ~~3~~ | — | 削除(相手チーム48dimに包含) |
| **相手チーム6体** | **0** | **48** | 6スロット×8dim |
| **自分ステ変化** | **0** | **7** | atk/def/spa/spd/spe/acc/eva |
| **相手ステ変化** | **0** | **7** | 同上 |
| 天候 | 8 | 8 | — |
| **テレイン** | **0** | **4** | electric/grassy/misty/psychic |
| **設置技** | **0** | **6** | 両陣×(SR,まきびし,どくびし) |
| メガフラグ | 2 | 2 | — |
| 強制交代/トラップ | 2 | 2 | — |
| アクションマスク | 9 | 9 | — |
| **合計** | **101** | **186** | **+85** |

### 相手チーム6体のエンコード（8dim/スロット）

| フィールド | エンコード |
|-----------|-----------|
| type1_idx | 主タイプのインデックス / 18.0 |
| type2_idx | 副タイプのインデックス / 18.0 (単タイプは0) |
| physical_bias | (base_atk - base_spa) / 200.0 |
| bulk_rating | (base_hp + base_def + base_spd) / 600.0 |
| base_spe | base_spe / 200.0 |
| revealed | 1.0 if バトル中に登場済み |
| hp_fraction | 判明しているHP% (未登場は1.0) |
| alive | 0.0 if ひんし確認済み |

### 新規ヘルパー関数

| 関数 | 目的 |
|------|------|
| `_parse_revealed_moves()` | ログから相手の使用技を抽出 |
| `_parse_boosts()` | ログからステータス変化を抽出 |
| `_parse_terrain()` | ログからテレインを抽出 |
| `_parse_hazards()` | ログから設置技状態を抽出 |
