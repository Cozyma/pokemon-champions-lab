# 技obsの情報欠落修正・報酬設計の課題整理（2026-04-30）

## 1. 発見: RLが積み技を一切使わない

バトルRL v4(品質報酬)で62%に到達したが、**setup_attempts=0**。
ヒューリスティクスでは積みが使われているのにRLでは使われない。

### 原因

技obsが`[bp, eff, stab, priority, category]`の5dimで、Status技(bp=0)は全て**ゼロベクトル**になる。
RLから見ると「Swords Dance」も「何もしない」も同じに見える。

積み技の情報がobs上で**完全に不可視**だった。

### 修正(278→294dim)

技obs を5dim→9dimに拡張:

| 追加フィールド | 内容 | 例 |
|--------------|------|-----|
| is_setup | 自己ブースト技か | Swords Dance→1.0 |
| boost_total | ブースト合計/6 | Iron Defense(+2)→0.33, Quiver Dance(+3)→0.5 |
| is_heal | 回復技か | Recover→1.0 |
| is_debuff | 相手へのデバフ/状態異常 | Toxic→1.0, Icy Wind→1.0, Will-O-Wisp→1.0 |

## 2. 報酬設計の試行と課題

### v4: 品質ベース報酬(HP変化 + KO + 品質ペナルティ)
```
reward = HP変化×0.1 + KO×0.3
       - 免疫技×0.3 - 無駄積み×0.2/turn - 悪交代×0.2
       + 積みKO×0.2
```

**結果**: 62%到達。だが**積みが0回** — 積みが短期的にHP変化=0+被ダメ=負で報酬マイナスになるため。

### v5: 行動回数バランス報酬
```
balance = min(my_survive_turns, my_ko_turns) + (alive-1)*3 - opp_estimate
reward = (balance_now - balance_prev) * 0.05
```

**結果**: 41%に悪化。問題:
1. 積みの効果が**即座に**balance改善として反映 → 脳死積みの危険
2. バランス推定が粗い(相手の生存ターンが`opp_alive*3`固定)
3. 行動回数バランスの変動が大きすぎて学習が不安定

## 3. 未解決課題: 報酬設計

### ヒューリスティクスの判断 vs obs/報酬の対応表

| 判断 | ヒューリスティクス | obs情報 | 報酬信号 | 状態 |
|------|-----------------|---------|---------|------|
| 攻撃技選択 | _score_move | ○ bp/eff/stab | ○ HP変化+KO | **OK** |
| 積み判断 | 行動回数理論 | **○ 修正済** is_setup/boost | **△** 要再設計 | **課題** |
| 回復判断 | HP閾値+壁判定 | **○ 修正済** is_heal | △ 行動回数に含まれるべき | **課題** |
| 毒撒き | survive≥4判定 | **○ 修正済** is_debuff | **×** 蓄積ダメの価値が報酬に反映されない | **課題** |
| 交代判断 | OHKO/matchup | ○ 控え全情報 | △ 悪交代ペナルティ | 部分的 |
| ハザード設置 | 相手残数≥3 | ○ 設置技obs | **×** 設置の価値が報酬にない | **課題** |
| メガ進化 | タイプ変化評価 | ○ can_mega | ○ 暗黙(勝率に反映) | OK |

### 報酬設計の方向性(未実装)

**選択肢A: v4に戻し、積みKOボーナスを大きくする**
- 保守的。「積んで回収した場合のみ報酬」
- 問題: 積み始めのインセンティブがない(回収まで報酬なし)

**選択肢B: 行動回数バランス報酬を精緻化**
- 理論的に正しいが、推定精度が報酬品質に直結
- 問題: 脳死積みの抑制が難しい

**選択肢C: ハイブリッド**
- 基本はv4(HP変化+KO)で安定した学習
- 積み技は「積み後にKO or 行動回数改善が確認された時点で遅延報酬」
- Toxic/ハザードは「定数ダメ蓄積」を毎ターン小さな正の報酬で反映

## 4. 次のアクション

1. **報酬をv4に戻す**(行動回数バランス報酬は不安定)
2. **技obs(294dim)を維持**
3. 積みの報酬設計を再検討:
   - 積みKOボーナスを+0.3〜0.5に拡大
   - または積み後の攻撃で「ブースト前より多くダメージを与えた」場合にボーナス
4. Toxic/ハザードの報酬を検討(蓄積ダメージの価値)
5. 294dim + 修正報酬でバトルRL再訓練
