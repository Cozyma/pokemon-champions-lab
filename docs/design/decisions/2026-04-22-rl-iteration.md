# RL訓練イテレーションとヒューリスティクス並行改善（2026-04-22）

## 背景

前日（4/21）にRL Phase 0の基盤を構築。リプレイ収集（650件）、模倣学習（Stage 1: 82%）、FastBattleEnv（1秒/戦）、PPO初回訓練（固定マッチアップで75%→過学習で20%）まで到達。対戦相手プールのランダム化を実装し、再訓練を開始した状態で前日を終了。

## 前日のロングラン結果（旧PPO、93次元obs）

夜間に80kステップ訓練を実行したが、5kチェックポイント（40%）以降は10k到達前にプロセスが遅延。旧ヒューリスティクスAI（積み連打バグ等あり）が対戦相手で、速度が遅かった。

---

## 1. メタ分析

1,092件のリプレイ（レート1100-1475）から環境メタを分析。

**主要発見:**
- Garchomp使用率41%（環境の軸）
- Clefable場にいる時の勝率71.8%（1,079サンプル）
- 積み技がTOP: つるぎのまい(2位)、めいそう(4位)、コスミックパワー(9位)
- メガ使用率: Charizard-X > Lopunny = Gengar > Clefable

**Clefableの負けパターン分析（高レート帯）:**
- 43%が未選出で敗北（選出判断の問題）
- 43%が積み中に高火力で突破（Cosmic Power中にFlare Blitz等）
- メガシンカ前の耐久不足で積みが間に合わない

→ 積み判定の安全性チェックが必要と判明。

**EV/stat補正**: チャンピオンズのstat計算式（`base + EV + 20`）はEV32で本編EV252と同じ実数値。「EVが低いから耐久が低い」は誤り — 文書を修正。

## 2. ヒューリスティクスAI改善（積み判定の全面刷新）

### 積み判定
**Before**: HP=100% AND matchup>0 なら積む。+6上限チェックなし。
**After**:
1. 積んでいるターンに被弾で倒されないか判定
2. 積み+回復で受けが成立するか（防御ブースト後の被ダメ < 回復量）
3. +6到達で停止
4. 積み完了後はslusfest判定（殴り合いで勝てるなら攻撃優先）

**効果**: 30ターン42積みの試合 → 13ターン1積みに。Corviknight: Iron Defense×3 → Body Press KOのフロー確立。

### ブースト保護と交代
- 積みブーストがある間は原則交代しない
- ただし**slugfestで負ける場合は交代を許可**（ブーストを捨てる判断）

### ダメージ軽減特性
`ability_damage_modifier()`を新設:
- Thick Fat: 炎/氷 0.5x（メガフシギバナ）
- Filter/Solid Rock: 弱点 0.75x
- Purifying Salt: ゴースト 0.5x
- Heatproof/Water Bubble: 炎 0.5x
- Ice Scales: 特殊 0.5x

`_score_move`で確定特性なら直接適用、推定なら平均化。

### 中間技選択（ピボット判定）
有利対面（matchup > 1.5）で相手の交代を予測:
- U-turn/Volt Switch: スコア80（ダメ+交代先確認）
- ステルスロック: スコア60×残数（未設置時のみ）
- 状態異常技: スコア50
- 攻撃技: 相手チーム全体へのカバー率で評価

### 状態異常技のスコアリング
basePower=0の変化技を初めて評価:
- おにび: 120（物理相手）/ 30（特殊）
- でんじは: 110（相手が速い）/ 40
- あくび: 80
- どく: 100（回復持ち相手）/ 50
- 催眠技: 130×命中率

### とんぼがえり優先
交代判定時にU-turn/Volt Switch持ちなら素の交代より優先。
ただし**相手に先制されて倒される場合は素の交代**（交代先が耐性で受ける方が良い）。

### 選出の特性考慮
- かげふみ（Shadow Tag）: 不利対面のペナルティ-2.0。ただしとんぼがえり持ちは-0.5
- あついしぼう等: STAB攻撃力を半減補正して選出スコア計算

## 3. PPO訓練の世代推移

### Gen1: 旧PPO（デフォルトパラメータ）
- 1kステップ → 勝率0%。clip_fraction=0、entropy固定。失敗。

### Gen2: チューニング済みPPO（固定マッチアップ）
- lr=1e-3, ent_coef=0.05, n_steps=32
- 1k: 70%, 2k: 75%, 3k: 20%（entropy崩壊）
- 固定マッチアップへの過学習が原因

### Gen3: MaskablePPO + opponent pool（93次元obs）
- sb3-contrib MaskablePPO導入。アクションマスクが学習時に反映。
- 対戦相手を6チームからランダム選択。
- 6k: 60%で天井。早期停止発動（16kステップ）。

### Gen4: 重み移行 + 改善済みAI対戦（93次元obs）
- Gen3の重みをMaskablePPOに移行して継続訓練。
- ヒューリスティクスAI改善（積み修正等）が反映。
- 6k: 71%（Gen3の60%を突破）。ただしまだ旧obs空間。

### Gen5: 拡張obs（101次元）ゼロスタート
- 相手ステータス(5) + 特性フラグ(3)を追加。93→101次元。
- obs変更のためゼロから学習。
- **10k: 71%★**。ゼロからでGen4のベストに並ぶ。

### Gen6: Gen5重み → 最新AI対戦
- Gen5のベストモデル(71%)から再開。lr=1e-3固定。
- 対戦相手: ピボット判定、状態異常、選出特性考慮の最新AI。
- 4k: **68.6%** → 8k: 40%。**entropy崩壊で急落**。早期停止。
- mega-gengar: 0/5のまま。

### Gen7: ゼロスタート → 最新AI対戦
- ゼロから訓練（Gen6の崩壊を受けA/B比較目的）。lr=1e-3固定。
- 6k: **63%**（gengar 3/5達成）→ 8k: 29%。同じ崩壊パターン。16kで早期停止。
- 6k付近にピークが来る共通パターンを確認 → **lr decayの必要性**が判明。

### Gen8: Gen7重み + lr decay + ヒューリスティクス大改善
- Gen7ベスト(63%)から再開。**lr=5e-4→5e-5線形減衰**。評価ゲーム数を5→10に増加。
- ヒューリスティクス改善（後述§2.5）が反映。
- 6k: **78.6%★**（gengar **9/10**）→ 8k: 72.9%。崩壊幅が-6%に抑制（従来は-30%）。
- BrokenPipeErrorで10kで中断 → fast_env.pyにハンドリング追加。

### Gen9: Gen8重み + さらに低lr（進行中）
- Gen8ベスト(78.6%)から再開。lr=3e-4→3e-5。
- 全ヒューリスティクス改善反映済み。進行中...

## 2.5. ヒューリスティクスAI追加改善（Gen6-8間）

### Scrappy（きもったま）対応
`_score_move`でノーマル/格闘技のゴースト免疫をバイパス。Mega Lopunnyの格闘技がMega Gengarに正しくスコア付けされるようになった。

### カバレッジ技の被ダメ推定
`_estimate_opponent_max_damage`をSTAB技のみ→**非STAB抜群技(100bp)**も考慮するよう拡張。
- **Before**: Gengar(ゴースト/毒)→Lopunny(ノーマル)はSTABゴースト=免疫、毒=等倍で低推定
- **After**: 格闘カバレッジ(Focus Blast)→ノーマル=2x抜群を検出 → OHKO判定が正しく発動

### active pokemonのタイプ補完
Showdown request JSONはactive側のtypesも省略することがある。`_get_pokemon_types`のpokedexフォールバックを`_choose_action`冒頭で適用。
- **Before**: my_types=[]で被ダメ推定が全て0 → 積み安全チェックが機能しない
- **After**: pokedex lookupでtypes取得 → カバレッジ被弾のOHKO検出が正常動作

### 低スコア交代
最高スコア技 < 40の場合「有効打なし」と判定して交代。
- **Before**: Garchomp vs てっぺきCorviknight → 等倍Stone Edge連打4ターン
- **After**: 有効打なしと判断して即交代

### 捨てポケモン判断
HP ≤ 20%かつOHKO確定なら交代せず犠牲にする。交代先が無傷で出られる方が被弾総量が少ない。
- RLの報酬に被KOペナルティを入れる代替としてヒューリスティクス側で対処

### 効果
mega-gengar-team相手: **全敗 → 5戦5勝**（ヒューリスティクス同士）。PPO訓練でも0/5 → **9/10**。

## 4. 技術的発見

### MaskablePPOの効果
通常PPO（マスクなし）→ MaskablePPO（sb3-contrib）で、無効な行動への確率割当がなくなり学習効率が向上。同じステップ数で60%（Gen3）→ 71%（Gen4/5）。

### ヒューリスティクスAI改善による訓練速度向上
旧AI: 積み連打で1試合30ターン → 新AI: 効率的に13ターン。
結果: 5kステップに107分 → 2.5分。**15倍速化**。

### 観測空間拡張の効果
相手のステータス+特性情報（+8次元）を追加。ゼロから学習でもGen4のベスト71%に10kで到達。情報量の増加が学習効率を補う。

### lr decayによるentropy崩壊防止
Gen6/7で共通して6k付近にピーク→急落（-30%）するパターンを観測。
- **原因**: 固定lr=1e-3では方策が収束後も大きく更新され続け、学習した戦略を忘れる（catastrophic forgetting）
- **対策**: 線形lr decay（5e-4→5e-5）導入。Gen8では8kでの落ち込みが-6%に抑制。
- **評価ノイズ対策**: 5games/opp → 10games/oppに増加し分散を半減。

### mega-gengar突破（0/5→9/10）
3つの修正の複合効果:
1. **Scrappy**: Mega Lopunnyの格闘技がMega Gengarにスコア付け → 攻撃優先で倒す
2. **カバレッジ被ダメ推定**: Focus BlastのOHKO脅威を検出 → 無謀な積みを抑止
3. **active types補完**: 被ダメ推定の前提条件が揃い、安全チェックが正常動作

### 残る弱点: mega-venusaur-charizardx 0/10
全世代を通じて唯一の全敗マッチアップ。要分析。

## 5. 現アプローチの振り返りと今後の方針

### 手動ループの評価

現在のサイクル:
```
ログ観察 → 問題発見 → ヒューリスティクス修正 → RL再訓練 → ログ観察 → ...
```

**有効だった点:**
- ドメイン知識の注入が直接的（Scrappy、カバレッジ推定、タイプ補完）
- バグ発見は手動でしか不可能（request JSONのtypes欠落等）
- CPU1台の予算制約下では試行回数に限界があり、手動改善の費用対効果が高い
- 0/5→9/10のようなブレークスルーはヒューリスティクス修正から生まれた

**スケールしない点:**
- 対戦相手を手動で強くする→再訓練のサイクルに人間がボトルネック
- ハイパーパラメータ(lr, ent_coef)を手動調整、再現性が低い
- 改善のたびにゼロからor重み継続の判断が必要

### 次フェーズ: Self-Play移行

手動ヒューリスティクス改善 → **Self-Play**（AlphaZero方式）への移行が次の大きなステップ。

| アプローチ | 効果 | コスト | タイミング |
|-----------|------|--------|-----------|
| **Self-Play** | 高 | 中（実装必要） | **次にやるべき** |
| 選出のRL化 | 高 | 中 | Self-Playと同時期 |
| Optuna自動HP探索 | 中 | 低 | Self-Play前に可能 |
| カリキュラム学習 | 中 | 中 | Self-Playの補助 |
| PBT | 高 | 高（GPU必要） | 将来 |

**Self-Playの前提条件（満たしている）:**
- 78.6%の初期方策があり、ランダム方策からの立ち上げが不要
- FastBattleEnv（1秒/戦）で十分な試行速度
- MaskablePPOとaction_masks()が安定動作
- ヒューリスティクスのバグは概ね解消済み

**Self-Playで自動化されるもの:**
- 対戦相手の自動強化（手動改善サイクルが不要に）
- 天井のない学習（固定相手への過学習が原理的に起きない）
- mega-venusaur-charizardxのような苦手相手も自然に克服される可能性
