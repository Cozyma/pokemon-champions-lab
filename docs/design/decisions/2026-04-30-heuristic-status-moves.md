# ヒューリスティクスAI状態技対応・全チーム横断バグスキャン（2026-04-30）

## 背景

4/28の行動回数理論適用後、選出RL訓練を実施(ベースライン71%、選出RL 72%)。
RL訓練前にヒューリスティクスのバグを網羅的に洗い出すため、全32チームの組み合わせでバトルを実行し、0/3全敗マッチアップを分析。

---

## 1. 全チーム横断スキャン

### 方法

32チーム × ランダム8対戦相手 × 3戦 = 768戦。0/3全敗のマッチアップを抽出。

### 結果(修正前)

86件の0/3マッチアップ。特に多いチーム:
- **1leven-r2200(受けループ)**: 7敗 — Toxapexが毎ターンThroat Chop、Toxic/Recoverを使わない
- **template-c-hippo(バトン構築)**: 7敗
- **gusha-r2200(受けループ)**: 4敗

### 原因分析

`_score_move`がStatus技(bp=0)に0.0を返すため、受けループの生命線であるToxic+Recoverが選択されない。
攻撃技(Throat Chop 80bp)が唯一のスコア>0の技として毎ターン選ばれる。

---

## 2. 状態技の行動回数理論での位置づけ

| 技 | 行動回数上の効果 | 使用条件 |
|----|----------------|---------|
| **Toxic** | 毎ターン蓄積ダメ → 相手のaction_turnsを確実に減らす投資 | 相手が毒でない + 自分が4ターン以上生存可能 |
| **Will-O-Wisp** | 物理攻撃半減 + 定数ダメ → 相手の攻撃行動回数の価値を半減 | 同上 |
| **Recover等** | 自分のaction_turnsを回復 | HP<50% + 即死しない、またはHP<70% + 壁成立 |
| **Haze** | 相手のブースト(投資)を無効化 → 行動回数の投資を帳消し | 相手が+1以上のブーストを持つ |

---

## 3. 実装

ハザード除去と積み判定の間に状態技判定を追加:

```
_choose_action の処理順:
  1. forceSwitch
  2. 交代判断 (_should_switch_out)
  3. 先制KO技
  4. ハザード設置/除去
  5. ★ Toxic/Will-O-Wisp (NEW)
  6. ★ Haze (NEW)
  7. ★ Recovery (NEW)
  8. 積み判定 (行動回数理論)
  9. slugfest
  10. 通常攻撃
```

### Toxic/Will-O-Wisp判定
```python
if 相手が状態異常でない:
    survive_turns = _count_action_turns(HP, 被ダメ, 回復量)
    if survive_turns >= 4:
        → Toxicを使用
```

### Haze判定
```python
if 相手のブーストが+1以上:
    → Hazeを使用
```

### Recovery判定
```python
if HP < 50% and 即死しない:
    → 回復技を使用
if HP < 70% and 壁成立(被ダメ < 回復量):
    → 回復技を使用
```
